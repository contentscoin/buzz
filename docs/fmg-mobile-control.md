# FMG 모바일 PC 제어 (.26)

FMG Android 1.2.1은 PC의 FMG 커스텀 Buzz와 페어링한 소유자 계정으로
`https://fmg.communities.buzz.xyz`에서 제어 요청을 보낸다. PC Buzz가 실행 중이고
같은 소유자의 FMG 커뮤니티가 선택되어 있어야 한다. Hostinger 작업·문서 조회와
PC 에이전트·프로젝트 관리는 서로 다른 경로다.

## 확인한 현상

- PC에 .25가 설치됐고 FMG 커뮤니티·소유자 공개키가 일치한다.
- PC의 암호화된 모바일 제어 기록은 존재한다.
- 사용자는 Android 1.2.1 설치 후 PC 제어 응답 시간 초과를 보고했다.
- PC 저장소의 에이전트 인스턴스 44개 중 7개는 이전 릴레이 주소가 비어 있다.
  이전 모바일 목록 필터는 빈 주소를 URL로 파싱하므로 목록 전체가 실패한다.
- 실제 전화의 시간 초과 원인이 수신기 초기화·구독·응답 전송 중 어느 단계인지
  아직 독립적으로 확인하지 못했다. 빈 주소 결함은 목록 경로의 별도 확인된 결함이다.

## .26 변경

- 구독 초기화에 종료 신호를 전달한다. 이전 화면의 초기화가 종료돼야 다음
  수신기가 잠금을 획득할 수 있다. 구독이 거절됐을 때 준비됐다고 처리하지 않는다.
- 초기화는 20초 안에 끝나야 하며 실패 시 지수 간격으로 최대 4회 시도한다.
  손상된 기록·사용 불가능한 잠금은 자동 반복하지 않는다. 이후 사용자가 재연결한다.
- 릴레이 재연결 후 기존 수신기를 다시 생성한다. 변경 요청을 자동 재전송하지 않는다.
- FMG 센터는 수신기 상태, 검증한 요청 수신 수, 릴레이가 수락한 응답 수,
  최근 작업 종류와 제한된 오류 코드를 표시한다. 입력·결과·비밀번호·토큰을
  상태 기록에 저장하지 않는다. 수신 준비와 실제 휴대폰 연결 완료를 구분한다.
- 목록은 PC와 같은 네이티브 에이전트 인스턴스 목록을 사용한다. 이전 릴레이
  주소로 필터링하지 않는다. 모든 실행과 변경은 현재 소유자·커뮤니티를
  네이티브 명령 및 실행 전 검사로 확인한다.
- 큰 결과가 오류 응답에 남아 암호화 한도를 넘지 않게 한다. 오류는 작은
  응답으로 전달하고, 불명확한 변경의 원래 요청 기록은 유지한다.

## 기기에서 확인할 순서

1. PC .26 업데이트 적용 후 FMG 센터의 `PC · 모바일 제어 연결`을 확인한다.
2. 휴대폰 FMG 에이전트에서 `PC 연결 / 새로 고침`을 누른다.
3. PC 수신·응답 수의 증가와 휴대폰 목록을 확인한다.
4. 같은 방법으로 프로젝트 목록을 확인한다.

수신 수가 0이면 요청 도달·검증 단계, 수신 수만 증가하면 PC 처리·응답 전송
단계, 응답 수도 증가하지만 휴대폰이 시간 초과하면 휴대폰 수신·검증 단계를
우선 조사한다. 카운터는 현재 수신기 세대에만 해당하며 재연결하면 초기화된다.
공식 앱·계정·대화를 삭제하거나 새 계정을 만들 필요는 없다.
